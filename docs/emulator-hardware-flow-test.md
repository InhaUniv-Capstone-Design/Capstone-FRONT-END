# 에뮬레이터·약통 흐름 시험

지금 소스로 만든 APK를 에뮬레이터에 설치하고, 약통을 연결한 뒤 가입부터 복약 이력까지 따라간다. 본인을 먼저 끝내고, 같은 에뮬레이터에서 대리인을 이어 한다.

한 행은 동작 하나다. 그 행의 기대만 보고 판정한다. 옆 행이 실패해도 이 행을 실패로 옮기지 않는다. 경우의 수를 곱하지 않는다. 본인 흐름에서 본 입력 검증을 대리인에서 다시 하지 않는다.

10장의 JVM 단위 시험, JMeter 부하, DUR 원본 대조는 이 문서에 넣지 않는다. 그 판정은 [chapter-10-test-plan.md](chapter-10-test-plan.md)에 남긴다. 화면에 같은 동작이 있으면 이 문서의 행으로만 판정한다.

## ID

`역할-단계-번호`다. 역할과 단계 이름은 문서 전체에서 같다.

| 역할 | 뜻 |
| --- | --- |
| P | 본인 |
| C | 대리인 |

| 단계 | 뜻 |
| --- | --- |
| IN | 설치 |
| SU | 가입 |
| LI | 로그인 |
| RG | 약 등록 |
| ML | 약 목록 |
| PB | 약통·하드웨어 |
| HM | 홈 |
| TK | 복용 체크 |
| HS | 복약 이력 |
| GR | 그래프 |
| ST | 설정·알림·연동 |
| LO | 로그아웃 |

번호는 그 단계 안에서의 순서다. 표를 위에서 아래로 읽으면 진행 순서가 된다. ID 사전순으로 뛰지 않는다. 약통 100회·30회는 본인 복약 이력을 본 뒤에 하고, ID는 `P-PB`로 둔다.

갈래는 셋이다.

| 갈래 | 하는 일 |
| --- | --- |
| 본선 | 다음 단계로 가기 위해 한다 |
| 곁가지 | 한 번 확인하고 본선으로 돌아온다. 본선 약을 지우지 않는다 |
| 반복 | 약통 기록 횟수. 흐름을 막지 않으려고 이력 확인 뒤로 둔다 |

판정은 `통과`, `실패`, `미실행`, `설계 차이`, `서버 미구현`만 쓴다. 약통이 없거나 인증번호가 없거나 연동 행이 없으면 미실행이다. 실패로 채우지 않는다. 비밀번호, 인증번호, 시리얼, 비밀값은 이 문서에 적지 않는다.

## 준비

1. 에뮬레이터를 켠다. Android 8.0 이상이다.
2. 프로젝트 루트에서 `./gradlew :app:assembleDebug`로 APK를 만든다.
3. `adb install -r`로 그 APK를 설치한다. 이미 있으면 지우지 말고 덮어쓴다. 패키지는 `com.gamcho.yakyeon`, 화면 이름은 yakyeon2다.
4. 서버 주소는 빌드에 들어 있는 주소 그대로 쓴다. 시험하려고 localhost로 바꾸지 않는다.
5. 약통 1대를 충전한다. 에뮬레이터와 약통이 시험 서버와 통하게 연결한다. 약통 시계와 에뮬레이터 시계 차이가 1초를 넘으면 맞춘 뒤에 약통 행을 시작한다.
6. 회원 탈퇴, 본선 약의 삭제, 약통 초기화는 하지 않는다. 칸 비우기의 확인 버튼은 삭제처럼 보이지만 칸 배정만 해제한다.

약통이 서버에 붙지 않으면 `P-PB`, `C-PB`의 하드웨어 행만 미실행으로 둔다. 가입과 약 등록을 그 이유로 실패 처리하지 않는다.

## 대리인

같은 APK, 같은 에뮬레이터, 본인이 연결한 약통을 그대로 쓴다. APK를 다시 설치하지 않는다. 본인 P-LO-05로 로그인 화면에 있는 상태에서 시작한다.

입력 검증, 용량, 기간, 4시간 간격, 그래프 상세 칸은 본인 행에서 끝냈다. 대리인은 가입 유형, 연동, 권한, 그 복약자의 복용 체크와 이력만 본다. 약통 100회와 알림 30회는 다시 하지 않는다.

연동이 없으면 C-HM-04부터는 미실행이다. 동의 웹이 404이거나 서버 미구현이면 그 행은 서버 미구현이고, 연동이 필요한 다음 행은 미실행이다. 빈 화면을 조회 성공으로 적지 않는다.

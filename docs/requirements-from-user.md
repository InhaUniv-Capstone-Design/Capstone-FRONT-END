# 사용자 화면 명세서

이 문서는 2026-10-22에 사용자가 전달한 화면 설계서를 화면 단위로 다시 정리한 것이다. 기능 의도와 세부 조건은 원문 그대로 보존한다. 원문에 없는 화면 이동, 검증, 문구를 이 문서에서 보충하지 않는다.

피그마에서 확인한 레이아웃과 문구는 여기 적지 않는다. 대응 프레임과 차이는 [figma-frame-inventory.md](figma-frame-inventory.md), [figma-vs-spec-differences.md](figma-vs-spec-differences.md)를 본다.

원문의 `(완)`은 작성자가 붙인 표시다. 현재 저장소의 구현 완료를 뜻하지 않는다.

공통 헤더 규칙은 화면마다 반복하지 않는다. [common-design-rules.md](common-design-rules.md)의 확정 규칙을 따른다.

## 원문 공통 규칙

- 모든 페이지의 헤더는 볼드체다. 피그마에서 기본 굵기인 헤더도 통일 대상이다.

## 원문 절 구성

| 원문 절 | 원문에 포함된 항목 |
| --- | --- |
| (완)로그인 | 가입 동의 팝업, 회원가입 유형 선택, 회원가입 정보 입력 |
| (완)메인 홈 | 스플래시·로그인, 메인 홈, 약물 목록, 약 등록 동의, 약봉지 등록, 수기 수정, 약통 칸 선택, 복용시간 알림, 약물 알람 카드, 복약 일정과 수동 기록 모달 |
| (완)기타 | 복용 알림 |
| 그래프 | 스마트 약통 연결, 기기 검색으로 서술된 화면, 스마트 약통, 약통 설정 |
| 설정 | 설정, 프로필, 복약자 연동, 알림, 의료진 공유, 권한 설정, 서비스 안내 및 정보 동의 |

`그래프` 절의 본문은 약물 관계 그래프가 아니라 스마트 약통 흐름이다. 절 제목은 원문대로 유지한다.

## (완)로그인

### 1. 모달 / [팝업] 복약정보 등록 개인정보 수집·이용 동의

필요한 값

- 동의용 체크박스

동작

- 모든 체크박스를 체크하지 않으면 회원가입을 할 수 없다.
- 동의하면 `화면 / 회원가입 유형 선택`으로 넘어간다.

### 2. 화면 / 회원가입 유형 선택

필요한 값

- 본인 또는 대리인 선택

동작

- 둘 중에 하나만 선택할 수 있다.
- 둘 다 선택하지 않으면, 관리할 사람을 선택해달라는 문구가 뜬다.
- 본인 선택 시, 바로 `화면 / 회원가입 정보 입력`으로 넘어간다.
- 대리인 선택 시, 바로 `모달 / 복약자 정보 열람 동의`로 QR을 보여주고, `먼저 회원가입 진행하기` 버튼을 통해서 `화면 / 회원가입 정보 입력`으로 간다.

### 3. 화면 / 회원가입 정보 입력

필요한 값

- 이름: 문자열.
- 생년월일: 날짜형식 고정. 달력으로 입력.
- 휴대폰 번호: `인증번호 받기`를 누르면 3분 카운트다운이 표시되면서, 인증번호 입력 및 확인 칸이 생성된다.
- 아이디: 문자열. 중복확인을 통해 디비에 이미 등록된 것인지 확인해야 한다.
- 비밀번호: 문자열.
- 비밀번호 확인.

동작

- 이미 가입된 번호, 중복 아이디, 비유효 비번일 때 오류 팝업을 생성한다. 원문: 피그마에 없어서 새로 생성 필요.
- 필수 입력을 하지 않으면 빠진 항목을 언급하며 입력해달라는 문구가 뜬다.
- 성공하면 회원가입되었다고 성공 팝업을 생성한다. 원문: 피그마에 없어서 새로 생성 필요.
- 성공 팝업 후 `화면 / 스플래시·로그인`으로 넘어간다.

원문이 정하지 않은 것

- 비유효 비밀번호의 구체 규칙, 인증번호 불일치·만료·재전송, 성공 팝업의 확정 문장과 버튼.

## (완)메인 홈

### 1. 화면 / 스플래시·로그인

필요한 값

- 아이디: 문자열.
- 비밀번호: 문자열. eye-off를 추가해서 비밀번호를 확인할 수 있게 만든다.

동작

- 로그인 성공 시 `화면 / 메인 홈`으로 넘어간다.
- 로그인 실패 시 `회원정보가 일치하지 않습니다` 팝업을 생성한다. 원문: 피그마에 없어서 새로 생성 필요.

### 2. 화면 / 메인 홈

필요한 값

- `안녕하세요 [  ]님.`의 빈칸에 사용자 이름이 들어간다.
- `현재 n개 복용 중`. 복용 중인 약물 리스트 카운트.
- 아침, 점심, 저녁 중 복용한 것 아이콘에 색깔을 칠하고, 복용 현황 바를 채운다.
- `병용금기 등재 정보가 _건 있어요`. 등재된 내역 개수 카운트.
- 오늘 남은 복약은 남은 예정 건만 리스트로 출력한다.

동작

- 상단 박스 또는 `약 추가 등록하기`를 누르면 `화면 / 약물 목록·복약 관리`로 넘어간다.
- 오늘 남은 복약 박스를 누르면 `화면 / 복약 일정`으로 넘어간다.

### 3. 화면 / 약물 목록·복약 관리

필요한 값

- 맨 위에 복용 중인 약봉투 개수, 복용 중인 약 총개수가 출력된다.
- 약 등록 버튼.
- 복용 중인 약물은 약봉투(이름), 복용까지 남은 날짜, 복용 약 개수와 복용하고 있는 약 리스트로 출력된다. 각 묶음 맨 아래의 `복용 조기 종료` 버튼으로 복용을 종료할 수 있다.
- 맨 아래에는 복용 종료한 약물이 약봉투(이름), 복용 종료 표시, 복용 약 개수와 약 리스트로 출력된다.

원문 표기: `복욕 종료한 약물`. 의미는 복용 종료한 약물이다.

동작

- `약 등록하기`를 누르면 `화면 / 복약정보 등록 개인정보 수집·이용 동의`로 넘어간다.
- `복용 조기 종료하기`를 누르면 `모달 / 복용을 종료하시겠습니까?`로 넘어간다.
- 약물 리스트의 한 칸을 길게 누르면 `모달 / [팝업]약물 알람 카드`로 넘어간다.

### 4. 화면 / 복약정보 등록 개인정보 수집·이용 동의

필요한 값

- 동의 내용 스크롤.
- 체크박스.

동작

- `동의하고 약 등록` 버튼을 누르면 `화면 / 약봉지 등록 · 약통 사용 여부`로 넘어간다.

원문이 정하지 않은 것

- 체크박스를 끄면 버튼을 막을지.

### 5. 화면 / 약봉지 등록 · 약통 사용 여부

필요한 값

- 촬영하기 버튼.
- 촬영한 내용을 바탕으로 자동으로 채워진 하단 내역.
- 처방받은 병원(약봉지 이름). 문자열로 입력.
- 처방받은 약물 리스트.
- 약물 등록 안내 설명 글.
- `약통 없이 사용하기` 버튼.
- `약통에 넣기` 버튼.

동작

- `촬영하기`를 누르면 OCR로 사진을 촬영한 후, 인식한 내용으로 자동 완성한다.
- 모든 약을 하나씩 눌러 보며 잘 입력되었는지 확인해야 한다. 확인 완료 체크박스를 추가해야 한다.
- 등록되지 않은 약은 추가 등록으로 등록할 수 있다.

이 화면의 동작 항목에는 두 버튼의 이동 대상이 없다. 이동 문장은 아래 수기 수정 항목에 있다.

### 6. 화면 / 수기 수정

원문 표기: `화면에 필요힌 값`.

필요한 값

- 약물명. 검색 기능으로 자동완성.
- 복용량. 리스트 선택.
- 1일 복용 횟수. 아침/점심/저녁 체크.
- 복용 시점. 리스트 선택.
- 복용 기간. 달력.
- 삭제 버튼. 원문: 피그마에서는 생략되어 있는 부분.

동작

- 약물명 입력은 검색을 통해 선택할 수 있다. 이미 저장된 디비를 불러와 존재하는 약만 입력할 수 있게 제한한다. 원문: 검색창은 피그마에 디자인되어 있지 않다.
- 복용량은 0.5정–3정이다. 그 외 약 단위가 있다면 미리 전부 리스트해 두고, 사용자는 선택만 할 수 있다.
- 1일 복용 횟수는 아침/점심/저녁을 체크할 수 있다. 중복 가능하다. 1일 몇 회인지 파악하는 용도다.
- 복용 시점은 약봉지에서 주로 안내하는 문구를 미리 전부 리스트해 두고, 사용자는 선택만 할 수 있다.
- 복용 기간은 사용자가 정한 기간을 기준으로 복용한다. 단, 시작 날짜는 약봉지를 받은 날이어야 한다.
- 삭제 버튼을 누르면 `모달 / 약물을 삭제하시겠습니까? · 02`가 뜬다.
- `약통 없이 사용하기`를 누르면 `모달 / 피부과 복용시간 알림 설정`으로 넘어간다.
- `약통에 넣기`를 누르면 `화면 / 약봉지 등록 · 약통 칸 선택`으로 넘어간다.

작성자 메모. 이번 기능으로 확정하지 않음

- 추후 복용하지 않아도, 복용할 때 유통기한을 알면 좋을 것 같다는 문장이 있다. 현재 입력 조건으로 적힌 규칙은 시작일을 약봉지를 받은 날로 하는 것까지다.

### 7. 화면 / 약봉지 등록 · 약통 칸 선택

필요한 값

- 맨 위에는 방금 등록한 약물들이 요약된 박스가 있다.
- 1번 칸, 2번 칸, 3번 칸이 있다. 사용 중인 칸은 사용 중으로 선택할 수 없다.
- 사용 중이 아닌 칸을 눌러 선택한다.
- 앱 사용 안내 문구.

동작

- 비어 있는 칸을 누른 경우, `등록 완료` 버튼으로 `모달 / 피부과 복용시간 알림 설정`이 뜬다.

원문 표기: `등록완로`.

### 8. 모달 / 피부과 복용시간 알림 설정

필요한 값

- 맨 위 등록 완료 표시.
- 아침, 점심, 저녁 각각 알람이 울릴 시간.
- 최종 등록 버튼.

동작

- 시간 등록 시, 선택되지 않은 시간대(아침/점심/저녁)는 출력하지 않는다.
- 등록 버튼을 누르면 `화면 / 약물 목록·복약 관리`에서 추가된 내역을 확인할 수 있다.

### 9. 모달 / [팝업]약물 알람 카드

필요한 값

- 약물명은 검색으로 선택한다. 저장된 디비에 있는 약만 입력할 수 있다. 원문: 검색창은 피그마에 디자인되어 있지 않다.
- 복용량은 0.5정–3정이다. 그 외 약 단위가 있다면 미리 리스트하고, 사용자는 선택만 한다.
- 1일 복용 횟수는 아침/점심/저녁 체크. 중복 가능. 1일 몇 회인지 파악하는 용도다.
- 복용 시점은 약봉지에서 주로 안내하는 문구를 미리 리스트하고, 사용자는 선택만 한다.
- 복용 기간은 사용자가 정한 기간이다. 시작 날짜는 약봉지를 받은 날이어야 한다.
- 같은 향후 메모가 있다. 유통기한 표시는 이번 요구사항으로 확정하지 않는다.

동작

- 삭제 버튼을 누르면 `모달 / 약물을 삭제하시겠습니까?`가 뜬다. `· 02`가 아니다.
- `수정 완료`를 누르면 `모달 / 해당 약물을 수정하시겠습니까?`가 뜬다.
- 수정한 내용이 올바르지 않거나 전부 입력하지 않은 경우 `모달 / 복용 시간이 올바르지 않습니다.`가 뜬다.

### 10. 화면 / 복약 일정

필요한 값

- 주간 캘린더.
- 선택한 날짜.
- 해당 날짜에 복용한 기록.
- 완료, 누락, 예정, 지연으로 상태 표시.
- 누락인 경우 복용시간 수정 안내 문구 출력.

동작

- `복용 시간 수정`을 누른 경우 `모달 / 피부과 아침 약을 드셨나요?`를 출력한다.

원문 표기: `복용 시간 수전`.

### 11. 모달 / 피부과 아침 약을 드셨나요?

필요한 값

- 안내 문구.
- 체크박스 `먹었어요` / `안 먹었어요`.

동작

- 체크박스는 하나만 선택할 수 있다.
- `먹었어요`에 체크하면 `모달 / 어느 회차 약을 드셨나요?`로 넘어간다.
- `안 먹었어요`에 체크하면 `화면 / 복약 일정`으로 돌아온다.

### 12. 모달 / 어느 회차 약을 드셨나요?

필요한 값

- 안내 문구.
- 체크박스(복용 시간대).

동작

- 체크박스는 하나만 선택할 수 있다.
- 이전 회차는 복용 알림을 정했던 시간으로부터 3시간이 지나면 선택할 수 없다.

원문 표기: `이전회차는 는`.

이 항목의 동작에는 다음 모달로 가는 문장이 없다.

### 13. 모달 / 몇시에 드셨나요?

필요한 값

- 안내 문구.
- 시간 기록.

동작

- 사용자가 직접 시간을 입력한 후 `수동으로 기록하기` 버튼을 누르면 `화면 / 복약 일정`으로 돌아가며, 기록이 저장되었다고 안내한다. `화면 / 복약 일정 · 02`를 참고한다.

### 14. 화면 / 복약 일정 · 02

부가 설명

- `화면 / 복약 일정`에서 수동 기록한 화면을 나타낸다.
- 해당 회차가 3시간이 지나기 전에 수동으로 기록할 수 있다.
- 그 이후부터는 자동으로 `누락` 상태로 표시된다.

## (완)기타

### 1. 화면 / 복용 알림

설명

- 어떤 화면에서든 comment-alt 아이콘을 누르면 해당 내역을 확인할 수 있다.
- 전체, 정상, 지연, 누락으로 카테고리화한다.
- 복용 내역 열람 기간을 설정할 수 있다.
- 오늘, 어제, 3일 전부터는 날짜로 섹션을 구분한다.
- 해당 날짜에 현재 시간을 기점으로 복용했는지 여부를 확인할 수 있다.
- `화면 / 복용 일정` 탭의 일일 내역을 단순화하여 저장한 곳이다. 원문 화면 이름은 `복용 일정`이고, 위에서 정의한 프레임 이름은 `복약 일정`이다.
- 이 페이지에서는 최대 1년까지 확인할 수 있다.

## 그래프

절 제목은 원문 그대로다. 내용에 약물 관계 그래프는 없다.

### 1. 모달 / IoT 연결 전 동의 팝업

필요한 값

- 스마트 약통 아이콘.
- 연결 안내글.
- 기기 등록 버튼.

동작

- 기기 등록 버튼을 누르면 `화면 / 복약정보 등록 개인정보 수집·이용 동의 · 02`로 넘어간다.

### 2. 화면 / 복약정보 등록 개인정보 수집·이용 동의 · 02

필요한 값

- 검색 중이라는 로딩 아이콘. 원이 움직인다.
- 스마트 약통을 찾고 있다는 문구와 연결 방법 안내.
- 발견된 기기의 개수.
- 약통의 디바이스 이름이 출력되고, 연결할 약통을 클릭한다.
- 기기가 보이지 않는 경우 다시 검색.

동작

- 디바이스 이름이 출력된 박스를 누르면 `화면 / IoT 스마트 약통`이 나온다.
- 다시 검색 버튼을 누르면 디바이스 검색이 다시 반복된다.

이 절은 위 프레임 이름에 기기 검색 동작을 적었다. 피그마에서 같은 이름의 프레임이 어떤 내용인지는 명세서 밖의 사실이므로 차이 문서에 둔다.

### 3. 화면 / IoT 스마트 약통

필요한 값

- 와이파이 연결 여부 확인.
- 약통 n칸 사용 중.
- 3칸 각각의 칸 상태, 제목, 약물 요약 설명.
- 약통 설정 버튼.

동작

- 초기에는 0칸 사용 중이며, 각 칸이 전부 비어 있다.
- 앱으로 약물을 등록할 때 칸을 설정하면 각 칸에 하나씩 들어간다.
- 약통 상태에 따라 특정 약통 상태 알림을 보여줄 수 있다.
- 약통 설정 버튼을 누르면 `화면 / 약통 설정 상세`로 넘어간다.

### 4. 화면 / 약통 설정 상세

필요한 값

- 위쪽에 약통 기기 디바이스 이름.
- 연결 상태.
- 부저 알람 설정, LED 알람 설정.
- 기기 동기화. 원문: 경우를 대비하여.
- 연결 해제 버튼.

동작

- 부저 알람과 LED 알람은 수시로 켜고 끌 수 있다.
- 기기 동기화 시 최근 동기화 시간이 업데이트된다. 원문 표기: `없데이트`.
- 연결 해제 버튼을 누르면 연결을 해제하겠습니까 팝업이 뜨고, 확인하면 `모달 / IoT 연결 전 동의 팝업`으로 돌아간다.

## 설정

### 1. 화면 / 설정

필요한 값

- 프로필 및 계정관리.
- 복약자 연동 관리.
- 알림 설정.
- 복약 이력 공유.
- 권한 설정. 원문: 새로 추가.
- 서비스 안내 및 정보 동의.

동작

- 프로필 및 계정관리를 누르면 `화면 / 프로필 계정관리`로 간다.
- 복약자 연동 관리는 대리인의 앱 사용인 경우에만 나타난다. `화면 / 복약자 연동 (대리인 회원의 경우에만 나타남)`으로 간다.
- 알림 설정을 누르면 `화면 / 알림 설정`으로 간다.
- 복약 이력 공유를 누르면 `화면 / 의료진용 복약 이력 공유`로 간다.
- 권한 설정을 누르면 `화면 / 권한 설정`으로 간다. 원문: 화면 생성 필요.
- 서비스 안내 및 정보 동의를 누르면 `화면 / 서비스 안내 및 정보 동의 메인`으로 간다.

### 2. 화면 / 프로필 계정관리

필요한 값

- 이름, 생년월일, 휴대폰 번호가 나타난다.
- 이름은 앱 사용자의 이름만 보여 준다.
- 생년월일, 휴대폰 번호는 x로 일부 마킹되어 출력된다.
- 비밀번호 변경.
- 로그아웃, 탈퇴.

동작

- 비밀번호 변경 시 기존 비밀번호, 새 비밀번호, 새 비밀번호 확인 순으로 입력한다. 원문: 새로 생성 필요.
- 로그아웃 시 `로그아웃 하시겠습니까?` 문구가 출력된다.
- 회원 탈퇴 시 기존 비밀번호, 탈퇴 사유, 데이터 보관 안내 순으로 입력한다. 원문: 새로 생성 필요.

### 3. 화면 / 복약자 연동 (대리인 회원의 경우에만 나타남)

필요한 값

- 복약자 연동 중.
- 연동된 복약자: 성명, 관계, 전화번호, 나이. 나이는 원문에 추가라고 적혀 있다.
- 연동 해제.
- 복약자 권한 범위 설정.

동작

- 연동 해제를 누르면 `복약자가 다시 연동을 허락하기 전에는 복약 관리를 할 수 없어요` 문구를 출력한다.
- 복약자 권한 범위 설정을 누르면 `화면 / 복약자 연동 - 먼저 본인 회원가입을 한 후, 복약자 등록하는 경우`로 간다.

### 4. 화면 / 복약자 연동 - 먼저 본인 회원가입을 한 후, 복약자 등록하는 경우

필요한 값

- 복약자 정보 열람 동의.
- 안내 문구.
- QR 코드 생성.
- 안내 문구.
- QR 링크 바로가기.

동작

- QR 링크 바로가기를 누르면 복용자 권한 관리용 웹이 자동으로 열린다.

### 5. 화면 / 알림 설정

필요한 값

- 복용 시간 알림, 설명, 온오프 버튼.
- 미복용 알림, 설명, 온오프 버튼.
- 복용 종료 예정 알림, 설명, 온오프 버튼.
- 약통 상태 알림, 설명, 온오프 버튼.

동작

- 각 버튼을 끄고 켤 수 있다.
- 약통 상태 알림을 누르면 `화면 / 알림 설정 · 02`로 넘어간다.

### 5-1. 화면 / 알림 설정 · 02

필요한 값

- 약통 열림 알림, 설명, 온오프 버튼.
- 복용 알림, 설명, 온오프 버튼.
- 미복용 알림, 설명, 온오프 버튼.
- 기기 이상 감지, 설명, 온오프 버튼.

동작

- 각 버튼을 끄고 켤 수 있다.

### 6. 화면 / 의료진용 복약 이력 공유

필요한 값

- 공유 기간 설정과 설정 버튼.
- 복약 기록과 포함/제외 버튼.
- 복약 기간과 포함/제외 버튼.
- 현재 복용 중인 약물과 포함/제외 버튼.
- 병용금기 등재 정보와 포함/제외 버튼.
- 약물 복용률과 포함/제외 버튼.

동작

- 포함/제외 버튼 중 하나만 선택할 수 있다.
- 공유 기간 설정을 하면 `모달 / 공유 기간 변경 팝업`이 뜬다.
- PNG 내보내기를 누르면 `잠시만 기다려 주세요` 문구 후 미리보기 화면이 출력된다.
- `저장하시겠습니까` 문구를 통해 이미지를 저장할 수 있다.
- PNG 형식은 아직 미정이다.

### 7. 권한 설정

원문: 추가 필요. 화면 생성 필요.

필요한 값

- 알림 권한과 온오프 버튼.
- 카메라 권한과 온오프 버튼.

동작

- 온오프 버튼으로 끄고 켤 수 있다.

### 8. 화면 / 서비스 안내 및 정보 동의 메인

필요한 값

서비스 안내 문구

- 서비스 이용약관.
- 개인정보 및 민감정보 처리방침.
- 약물 등록 동의.
- 약통 등록 동의.

동의 철회

- 서비스 이용약관: 동의 철회 버튼.
- 개인정보 및 민감정보 처리방침: 개인정보 수집 및 이용 동의 철회 버튼, 민감정보 처리 동의 철회 버튼.
- 약물 등록 동의: 복약 정보 수집 및 이용 동의 철회, 복약 정보 수집 및 이용 동의 철회. 원문에 같은 항목이 두 번 있다.
- 약통 등록 동의: 기기 정보 수집 및 이용 동의 철회.

복약 정보 보관

- 그에 대한 설명.

동작

- 서비스 안내 문구를 각각 누르면 해당 페이지로 넘어간다. 각 페이지는 읽기 전용이다.
  - `화면 / 서비스 이용약관 상세`
  - `화면 / 개인정보 및 민감정보 처리 방침 상세`
  - `화면 / 약물 등록 동의 상세`
  - `화면 / 스마트 약통 연결 안내`

## 명세서가 새 화면 또는 새 팝업이라고 밝힌 항목

| 항목 | 원문 표현 |
| --- | --- |
| 가입 오류 팝업 | 피그마에 없어서 새로 생성 필요 |
| 가입 성공 팝업 | 피그마에 없어서 새로 생성 필요 |
| 로그인 실패 팝업 | 피그마에 없어서 새로 생성 필요 |
| 비밀번호 변경 | 새로 생성 필요 |
| 회원 탈퇴 | 새로 생성 필요 |
| 권한 설정 | 새로 추가, 화면 생성 필요 |
| 약통 연결 해제 확인 팝업 | 팝업이 뜬다고 서술. 기존 프레임 이름은 없음 |
| 연동 해제 문구 | 문구 출력. 프레임 이름은 없음 |
| 로그아웃 문구 | 문구 출력. 프레임 이름은 없음 |
| PNG 미리보기와 저장 확인 | 미리보기 화면 출력. PNG 형식은 미정 |
| 약물 검색창 | 피그마에 디자인되어 있지 않음 |
| 확인 완료 체크박스 | 추가 필요 |
| 비밀번호 eye-off | 추가해서 만들 것 |

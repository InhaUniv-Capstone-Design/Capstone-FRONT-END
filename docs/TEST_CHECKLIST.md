# 약연 APK 점검 체크리스트

대상 파일은 `dist/Yakyeon_Test_v3.0.apk`입니다. 패키지는 `com.gamcho.yakyeon`, 화면 이름은 yakyeon2입니다. 개발자가 아닌 팀원이 휴대폰에 설치한 뒤 결과를 적습니다.

판정은 **성공**, **실패**, **미확인** 중 하나만 적습니다. 기기가 없거나 계정이 없어 못 한 항목은 미확인으로 두고, 비고에 이유를 적습니다.

## 점검 전에

- 앱을 지우거나 데이터를 삭제하지 않습니다. 같은 약을 실패했다고 여러 번 등록하지 않습니다.
- **삭제**, **종료**, **회원 탈퇴**, **연결 해제**는 확인 창을 읽기 전에는 누르지 않습니다. 약통 **칸 비우기**의 확인 버튼은 **삭제**라고 보이지만, 문장은 칸 배정만 해제한다는 뜻입니다.
- 시리얼, 비밀값, 비밀번호, 인증번호는 이 문서에 적지 않습니다.
- 화면이 다르면 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)의 같은 증상을 보고, 개발팀에 보낼 정보는 그 문서의 표를 채웁니다.
- 사용 순서는 [USER_MANUAL.md](USER_MANUAL.md)를 봅니다.

# 공통 디자인 규칙

화면별 명세는 이 문서의 확정 규칙을 반복하지 않고 여기를 참조한다.

출처를 둘로 나눈다. 사용자가 이번 작업에서 확정한 규칙과, 피그마 레이어에서 관찰한 사실이다. 관찰은 구현 규칙으로 승격하지 않았다.

## 사용자가 확정한 규칙

### 헤더 굵기

- 모든 페이지의 헤더는 볼드체다.
- 피그마에서 기본 굵기로 그려진 헤더도 같은 규칙의 대상이다.
- 개별 화면 명세에 이 문장을 다시 적지 않는다.

이 규칙의 출처는 사용자 요청이다. 피그마 시안의 현재 굵기를 따른다는 뜻이 아니다.

## 피그마에서 확인한 사실

아래는 `최종 정리안(레이어 수정 ver)` 메타데이터에서 반복해서 보인 형태다. 디자인 토큰으로 확정하지 않는다.

- 본 화면으로 보이는 프레임의 폭은 대부분 360이다. 동의 패널 일부는 284 또는 304다.
- 상태 표시줄의 시각 텍스트는 `9:41`이다. 예시 시각으로 보이며, 동작 규칙으로 적혀 있지는 않다.
- 여러 본 화면에 탭 이름 `홈`, `그래프`, `약통`, `설정`이 있다. 탭 텍스트가 확인된 프레임은 [figma-frame-inventory.md](figma-frame-inventory.md)에 표시했다.
- 가입, 동의 상세, 프로필, 알림 설정, 약통 설정, 복약자 연동, 의료진 공유 프레임에서는 그 탭 이름 텍스트가 보이지 않았다. 탭 바 부재로 단정하지 않는다.
- 브랜드 표기 `약연`, `藥緣 · 약과 사람을 잇다`는 스플래시·로그인 프레임에 있다.

## 확인하지 못한 디자인 속성

- 어떤 헤더가 볼드이고 어떤 헤더가 기본 굵기인지는 프레임별로 측정하지 않았다. 사용자는 두 가지가 섞여 있다고 밝혔다.
- 색, 서체 패밀리, 글자 크기, 간격, 모서리, 아이콘 에셋은 이번 분석에서 수치로 추출하지 않았다.
- 긴 본문 문구의 잘린 뒷부분은 확인하지 못했다.

이 항목들은 공통 규칙이 아니다. 측정 전에 토큰 값으로 적지 않는다.

## 이번 읽기에서 확인하지 못한 범위

- 페이지 전체에 대한 디자인 코드 호출은 실패했다. 반환 내용은 선택된 레이어가 없다는 메시지였다.
- 개별 프레임의 스크린샷, 색, 서체 크기, 자간, 헤더 font-weight는 프레임마다 측정하지 않았다.
- 텍스트 레이어 이름이 긴 문장을 중간에서 자르고 있다. 아래 문구는 레이어 이름에 남은 범위만 기록한다. 잘린 뒤를 이어서 쓰지 않는다.
- 따라서 이 문서는 프레임의 존재, 이름, 크기, 주요 구성, 레이어 이름에 남은 문구까지를 확인한 결과다. 시각 시안과의 픽셀 일치는 확인하지 않았다.

- 확인 완료 체크박스라는 이름의 레이어

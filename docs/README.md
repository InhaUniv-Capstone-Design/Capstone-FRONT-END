# 약연 사용 문서

이 폴더의 문서는 약연 Android 앱 4.0(`com.gamcho.yakyeon`)과 스마트 약통을 처음 쓰는 팀원을 위한 안내입니다. 앱 소스에 실제로 있는 화면과 문구만 적었습니다. 코드만으로는 확인하지 못한 동작은 **개발팀 확인 필요**로 표시했습니다.

## 어떤 문서를 볼까

| 문서 | 언제 보나 |
| --- | --- |
| [USER_MANUAL.md](USER_MANUAL.md) | 앱을 설치하고 기능을 따라 할 때 |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | 화면이 기대와 다르거나 버튼이 안 될 때 |
| [TEST_CHECKLIST.md](TEST_CHECKLIST.md) | APK를 받아 기능을 점검하고 결과를 적을 때 |

## 추천 순서

1. 저장소 맨 위 [README.md](../README.md)에서 `dist/Yakyeon_Test_v4.0.apk`를 설치합니다.
2. [USER_MANUAL.md](USER_MANUAL.md)의 PART 1을 따라 가입하고 로그인합니다.
3. 약을 넣을 때는 PART 2를, 약통을 쓸 때는 PART 4를 엽니다.
4. 막히면 그 화면 이름과 버튼 이름으로 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)를 찾습니다.
5. 점검 결과를 남길 때는 [TEST_CHECKLIST.md](TEST_CHECKLIST.md)에 적습니다.

화면 그림이 들어갈 자리는 각 문서에 `화면 캡처`로 비워 두었습니다. 캡처를 넣기 전에는 그 줄의 버튼 이름만 보고 따라 합니다.

앱 데이터나 서버의 약 정보를 지우는 조치는 매뉴얼에 적힌 확인 창의 문구를 읽은 뒤에만 진행합니다. 문제가 생겼다고 앱을 지우거나 같은 약을 다시 등록하지 않습니다.

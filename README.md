# 약연 (Yakyeon)

약 정보를 등록하고, 오늘 복용 일정을 확인하고, 스마트 약통 칸에 약봉투를 배정하는 Android 앱입니다.
복약 기록을 돕는 도구이며, 의료행위나 복약지도가 아닙니다.

## 테스트 APK

Android Studio나 환경 변수 없이 바로 설치할 수 있는 debug APK입니다. 서버 주소는 APK에 이미 포함되어 있습니다.

**다운로드:** [dist/Yakyeon_Test_v4.0.apk](dist/Yakyeon_Test_v4.0.apk)

| 항목 | 값 |
| --- | --- |
| 버전 | 4.0 (`versionCode` 4), debug |
| 패키지 | `com.gamcho.yakyeon` (런처 이름: yakyeon2) |
| 요구 사양 | Android 8.0 이상 (API 26) |
| 서버 | `https://kue200p7z3.execute-api.ap-northeast-2.amazonaws.com` |

### 설치

1. 위 APK를 휴대폰으로 받아 내 파일 앱에서 엽니다.
2. 설치가 막히면 **이 출처 허용 / 알 수 없는 앱 설치**를 켠 뒤 다시 설치합니다.
3. 앱 서랍에서 **yakyeon2**를 열고, 알림 권한을 허용합니다 (거부해도 로그인 가능).
4. PC에 연결한 경우: `adb install -r dist/Yakyeon_Test_v4.0.apk`

기존 버전이 설치되어 있으면 덮어쓰면 됩니다. 서명이 다른 동일 패키지 앱이 있으면 먼저 제거하세요.

### 설치 후 확인

- 팀 계정으로 로그인 (없으면 회원가입, 휴대폰 인증 필요)
- 홈 · 약물 등록 · 약통 · 복용 기록 · 설정 화면 이동 확인
- 서버 연결 실패 시 앱이 종료되지 않고 "서버에 연결할 수 없습니다"가 표시됨
- 약통 버튼 입력은 ESP32 기기가 계정에 연결된 경우에만 동작

## 앱 구성

| 탭 | 기능 |
| --- | --- |
| 홈 | 오늘 복용 일정, 미복용 체크, 병용금기 등재 건수 |
| 복약 일정 | 날짜별 복용 일정 |
| 그래프 | 함께 먹는 약의 병용금기 등재 여부 |
| 약통 | 연결된 약통(3칸), 칸 상태, 기기 등록 |
| 설정 | 계정, 알림, 연동, 약관 |

약 목록은 **내 약물** 화면에서 관리합니다 (등록 · 복용 시간 수정 · 칸 변경 · 종료/삭제).

## 주요 사용법 요약

- **회원가입/로그인:** 본인/대리인 선택 → 이름·생년월일·휴대폰·아이디(중복 확인)·비밀번호 입력 → 휴대폰 인증. 아이디 찾기/비밀번호 재설정은 로그인 화면에서 가능합니다.
- **약 등록:** 내 약물 → 동의 → 약봉투 사진(OCR) 또는 수동 등록. 병원명·약물명·용량·복용 횟수/시점·기간·복용 시각은 필수이며, OCR 결과는 저장 전 반드시 약봉투와 대조하세요.
- **복용 시간 규칙:** 회차 간 최소 4시간 간격, 아침·점심·저녁은 20:59까지, 취침은 23:59까지. 필요 시 약은 다른 회차와 함께 선택할 수 없습니다.
- **스마트 약통:** 약통 탭에서 시리얼번호와 비밀값으로 기기를 등록합니다. 빈 칸에만 약봉투를 배정할 수 있으며, 칸 비우기는 배정만 해제하고 복용 기록은 지우지 않습니다.
- **복용 체크:** 홈의 **드셨나요?**에서 먹은 약과 시각을 기록합니다. 오늘 기록만 입력/수정할 수 있습니다.
- **알림/설정:** 설정에서 복용·미복용·약통 상태 알림을 켜고 끌 수 있으며, 복약 이력 공유(PNG), 로그아웃, 회원 탈퇴도 설정에서 합니다.

## 버전별 변경 사항

- **4.0:** 약통 열림 알림 제거, 센서 감지 시 알림 없이 약통 화면 새로고침, 약봉투 카드 간격 조정. 이전 파일: [v3.0](dist/Yakyeon_Test_v3.0.apk)
- **3.0:** 병용금기 안내 문구 단순화, 새 약봉투 목록 최상단 표시, 복용 시각 그대로 저장, 사용 중인 약통 칸 잠금. 이전 파일: [v2.0](dist/Yakyeon_Test_v2.0.apk)

## 직접 빌드 (개발자용)

APK만 설치한다면 이 절은 필요 없습니다.

| 값 | 설명 |
| --- | --- |
| `yakyeon.apiBaseUrl` | 서버 주소. 비우면 기본 배포 주소를 사용. `gradle.properties` 또는 `-P`로 전달 |
| `app/google-services.json` | Firebase 설정 (저장소에 없음). FCM 포함 빌드 시에만 필요 |
| `local.properties` | Android SDK 경로 (저장소에 올리지 않음) |

```bash
./gradlew :app:assembleDebug -Pyakyeon.apiBaseUrl=https://kue200p7z3.execute-api.ap-northeast-2.amazonaws.com
```

> `http://localhost:8080`으로 빌드하면 휴대폰 자기 자신을 가리키므로, 팀 테스트에는 기본 배포 주소를 그대로 사용하세요.
